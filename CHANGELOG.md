# Changelog

## Unreleased

### Added

- TFTP: самообслуживание для доменных пользователей с номером из AD и конфигом в tftpboot — раздел «Мой телефон», отправка правок быстрых кнопок на модерацию.
- TFTP: вкладка «Модерация» для операторов — список заявок, просмотр изменений, принять/отклонить.
- TFTP: поле номера на быстрых кнопках (редактор и «Все кнопки») — цифры до 11 или строки перевода вида `*8` / `**` (в cfg — полностью, напр. `*8@1/f`, `**@1/f`); иконка ☎ у таких кодов недоступна.
- TFTP «Мой телефон»: в списке конфигов — только внутренний номер, без MAC.
- `upgrade.php` v15: таблица `@tftpboot_moderation_request`.
- Телефонная книга: легенда «Кружок статуса» видна администраторам и операторам (не обычным пользователям).
- `upgrade.php`: через 10 секунд после завершения — автоматический переход на главную (`WEB_URL`).
- Журнал изменений для администраторов: страница `logs` с поиском и пагинацией; ссылка в Настройки → Инструменты.
- Расширенный аудит в `pb_logs`: правки контактов и карты, массовые операции (sync, hide/show, purge, memcached), мутации TFTP (bulk, sync apply/undo, rescan, админ-каталог/политики).

- TFTP «Выбор телефона»: Fanvil по умолчанию, сортировка моделей по алфавиту («Прочие Fanvil» в конце), регистр названий вендоров.
- TFTP редактор Fanvil: секции SoftDss / Dsskey ConfigN (табы) / Sidekey, пустые слоты Type=1, обмен значений при DnD без смены порядка `#N`, сброс кнопки (× → Type 0 в cfg).
- TFTP редактор: все Fkey в SoftDss/Dsskey/Sidekey (в т.ч. Type 0), отдельные DSS-модули, суффикс `@1/bc` (иконка телефона, сохранение при DnD).
- TFTP редактор: сворачиваемые секции; «Кнопки на экране» (Sidekey) сверху свёрнут, «Софт кнопки» (SoftDss) снизу свёрнуты.
- TFTP редактор: подписи «Быстрый набор» (Dsskey), вкладки «Быстрый набор 1…N».
- TFTP Fanvil: ячейка AUTO (Type 2) — отключена иконка ☎; сохранение Value AUTO; поле SIP «Имя на экране».
- TFTP Fanvil: AUTO и SIP1… — Type 2, отключена иконка ☎; значения в cfg в верхнем регистре.
- TFTP редактор: подписи кнопок «Ячейка #N» вместо имён секций в cfg.
- TFTP редактор: оформление вкладок «Быстрый набор N», плавное мигание активной.
- TFTP: вкладки «Выбор телефона», «Все кнопки», «Синхронизация» — медленное зелёное мигание активной.
- TFTP редактор: плейсхолдеры полей «Подпись» и «Номер».
- TFTP Fanvil: F_SMS / F_MWI / F_RECORD (Type 3) с подписями СМС / Почта / Запись.

### Fixed

- TFTP self-service: запрос своих конфигов через `rpv()` (префикс таблиц); при отсутствии схемы v11+ и SQL-ошибках — без 500 для LDAP-пользователей.
- Вход через AD: после успешного `ldap_bind` больше не блокируется из‑за старого MD5 в `pb_users.passwd`; учётка с тем же логином без `UA_LDAP` переводится в LDAP; после проверки пароля восстанавливается bind сервисной УЗ для sync/прав.
- `upgrade.php` (v14): очистка `passwd` у пользователей с флагом `UA_LDAP`.
- Форма входа: подсказка, если указан логин без `domain\\user` или UPN при включённом LDAP.

- `upgrade.php`: одним запуском — все шаги с текущей `db_version` до `DB_VERSION` (fall-through); расширение `pb_config.value` до MEDIUMTEXT; исправлен SQL описания `db_version` на шаге 8.
- TFTP синхронизация (Fanvil): при «Применить изменения» пустые DSS-ячейки сбрасываются в Type 0; AUTO / F_SMS / F_MWI / F_RECORD приводятся к Type 2/3 как в редакторе «Выбор телефона».
- Настройки → «Очистить memcached»: исправлен URL (`memcached_flush` вместо несуществующего `flush_memcached`).

- TFTP: вкладка «Справочник» убрана — её кнопки на вкладке «Синхронизация»; предпросмотр синхронизации — «Проверить телефоны».
- TFTP: постраничный вывод в модальном справочнике номеров (тот же размер страницы, что у массовых кнопок).
- TFTP: короткое ФИО при AD, когда `displayName` только в `first_name` (не одна буква).
- TFTP: справочник и синхронизация — разбор нескольких номеров в `phone_internal`, игнор H.323/SIP/IP; поиск в модалке; ограничение высоты окна.
- TFTP: «Запросить данные» только при выбранном и настроенном HTTP API; подсказки на кнопках синхронизации; «Проверить телефоны» — справа.
- TFTP: «Проверить телефоны» — индикатор загрузки, сообщение при отсутствии отличий и при ошибке AJAX.
- TFTP: синхронизация только подписей кнопок быстрого набора (как «Массовые кнопки»); подтверждение применения; красная «Применить»; отмена последнего применения.
- TFTP: при отсутствии номера в справочнике — сверка дублирующих подписей по большинству кнопок; увеличены таймауты применения синхронизации (AJAX 10 мин, PHP 600 с).
- TFTP: номера 6XXX — сопоставление с 7XXX и поиск по фамилии на кнопке; «осиротевшие» 6XXX удаляются как в «Массовые кнопки».
- TFTP: синхронизация — выбор производителей на вкладке; из списка кнопок исключён собственный номер телефона (линия Cisco/Yealink и т.п.).
- TFTP: применение синхронизации — без полного перескана каталога; обновляется только изменённые конфиги (устраняет AJAX timeout).
- TFTP: вкладка «Все кнопки» (бывш. «Массовые кнопки»); в синхронизации по умолчанию выбран fanvil.
- TFTP: кнопка «Справочник» снова читает данные из БД, а не из внешнего источника (исправлен обработчик `onclick`).
- `DB_VERSION` в `pb.php` приведён к 13 (после миграции с `dial_keys_json` больше нет вечного редиректа на `upgrade.php`).
- Модуль TFTP: инициализация `tftpboot.js` после разметки (вкладки, редактор, модальные окна).
- Fanvil: модель из `Vendor Class ID`, расширен каталог моделей; в админке «неопознанные» — только при неизвестном вендоре.
- Fanvil: DSS-кнопки из секций `--Dsskey Config…--` / `--SoftDss Config--` (раньше перезаписывались между страницами).
- «Массовые кнопки»: уникальный справочник номер+ФИО; правка применяется ко всем конфигам.
- Кэш кнопок в `dial_keys_json` при сканировании (быстрая загрузка массового списка).
- «Массовые кнопки»: полный список при открытии вкладки; поиск фильтрует его на клиенте.
- «Массовые кнопки»: исправлен рендер таблицы (`LL` в JS — объект, не функция; падало на кнопке «Сохранить»).
- «Массовые кнопки»: постраничный список; размер страницы — в настройках телефонов (5–500).
- Подпись кнопки сохранения в массовом списке берётся из текущей локали.
- «Массовые кнопки»: удаление с подтверждением; в Fanvil — `Type :0`, пустые `Value` и `Title` во всех совпадающих конфигах.
- Fanvil: при изменении Fkey сохраняется исходное форматирование строки до «:».
- «Массовые кнопки»: подсказка по номеру без ФИО (файл и строка); колонка действий по ширине кнопок.
- «Массовые кнопки»: без кнопки обновления; список при смене вендоров; пустой список, если вендоры не выбраны.
- Каталог TFTP в БД дополняется определениями из `config/tftpboot_catalog.json` (новые модели Fanvil без ручного сброса).

### Added

- TFTP: Fanvil **X303G** в `config/tftpboot_catalog.json` (10 DSS по SoftDss Fkey1–Fkey10); при пересканировании — предложение добавить новые модели в каталог (диалог + `tftpboot_catalog_add_suggested`).

- Страница **Настройки** (`path=tools`): hub с карточками; «Инструменты», настройки по умолчанию и настройки телефонов — в модальных окнах; расширенные параметры `config` свёрнуты по умолчанию; пункт меню «Инструменты» переименован в «Настройки» (без выпадающего списка); «Настройки телефонов» перенесены с вкладки TFTP в hub.

- Модуль **Телефоны (tftpboot)**: сканирование каталога TFTP, дерево производитель/модель, визуальный редактор кнопок быстрого набора (popup, drag-and-drop), права оператора (только кнопки / настраиваемые секции / полный доступ), массовое изменение кнопок с фильтром по вендору, справочник «номер — ФИО», синхронизация подписей из справочника, API или произвольного JSON URL, авто-синхронизация по cron URL.
- Парсеры Fanvil, Cisco XML, Yealink, Grandstream, Eltex.
- Миграция БД версии 12: таблицы `@tftpboot_*`, право **TftpBoot** в разделе Permissions (бит `t`).
- Настройки модуля для администратора: `tftpboot_admin`, переопределение вендора/модели, политики LDAP-групп.
